# 🏋️‍♂️ Devfit - Diário de Treino & Evolução

O **Devfit** é uma aplicação web (PWA) moderna, leve e responsiva desenvolvida para ajudar praticantes de musculação a organizarem suas rotinas de treino, registrarem cargas e acompanharem sua evolução de força em tempo real.

---

## 🚀 Funcionalidades

- 📅 **Montagem de Treino Personalizada:** Suporte para divisões de 3, 4, 5 dias ou criação do zero.
- 📈 **Gráfico de Evolução:** Visualização dinâmica do ganho de carga ao longo do tempo por exercício.
- 🏆 **Recordes Pessoais (PRs):** Registro automático das maiores cargas atingidas com sistema de busca rápida.
- ⏱️ **Timer de Descanso Interativo:** Cronômetro integrado com alertas visuais e sonoros/vibração.
- 📆 **Histórico & Calendário:** Registro diário de treinos concluídos com visualização no calendário.
- 💾 **Backup de Dados:** Exportação e importação do histórico via JSON para não perder os dados.
- 📱 **Suporte PWA:** Pode ser instalado no celular como um aplicativo nativo.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização responsiva e tema Dark)
- **JavaScript (ES6+)** (Lógica de negócios e manipulação do DOM)
- **Chart.js** (Geração dos gráficos de evolução)
- **LocalStorage API** (Persistência dos dados no navegador)
